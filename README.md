# audio-file-inspector

<https://jack-hallybone.github.io/audio-file-inspector/>

To provide a fast, lightweight tool for playing common audio file formats and inspecting and verifying their basic technical properties, including duration, sample rate, encoding, and format.

This codebase was written by an AI agent, directed and reviewed by a human.
